# B/X Basic v0.1.2 encounter packet — public test fixture only

- **Authority:** Moldvay 1981 *D&D Basic Rules*, **B53**, wandering-monster table for dungeon level one; **B23/B53**, standard uncertain encounter distance.
- **DM-selected type:** goblins are a level-one table entry. The table gives **2–8** appearing; this demonstration fixture selects **two** from that printed range. There is no new distribution or rolled 1d20 table selection.
- **Separation:** 2d6 multiplied by 10 feet (20–120 feet). Dice are exclusively generated by the saved deterministic engine.
- **Contract:** `bx.encounter.v1`, exact source-labeled public fields. Validation refuses unrecognized IDs, sources, unknown fields (including hypothetical private notes), forged dice/counts, and unsupported selections.
- **Scope:** establishes contact identity in the **demonstration engine only**. Actual sight, geometry, surprise, conversation, reaction, combat, treasure, and resolution are not available. A pending contact blocks the next exploration turn until a later rules checkpoint.
- **Security:** The repository and browser save are public. The fixture deliberately contains no hidden adventure data. Game-private content must never be imported into static source or local storage; it requires a future authenticated server and explicit player-visible projections.
